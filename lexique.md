# Lexique

> Exemple de lexique : remplacez ces fiches par vos propres mots.

# Catégories
- infra: Machines, conteneurs et services
- technique: Outils et notions générales
- sécurité: Secrets et protection des accès

## Docker
- anglais: Docker
- catégorie: infra
- définition: Moteur qui fait tourner chaque service dans un conteneur isolé.
- voir: Conteneur

## Conteneur
- anglais: container
- catégorie: infra
- définition: Instance isolée d'un service, créée depuis une image.
- voir: Docker

## Proxy inverse
- anglais: reverse proxy
- catégorie: infra
- définition: Point d'entrée unique qui redirige chaque nom de domaine vers le bon service.

## Git
- anglais: git
- catégorie: technique
- définition: Gestion de versions du code.
- voir: Commit

## Commit
- anglais: commit
- catégorie: technique
- définition: Enregistrement d'un lot de modifications dans l'historique git, avec un message qui dit ce qui a changé.
- voir: Git

## Secret
- anglais: secret
- catégorie: sécurité
- définition: Mot de passe, clé ou jeton qui ne doit jamais apparaître en clair dans un fichier ou une commande.
